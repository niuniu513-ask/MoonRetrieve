# 本地 RAG 检索指南

RAG（Retrieval-Augmented Generation，检索增强生成）是一种把外部知识库与大型语言模型结合的技术方案。

## 为什么需要本地检索

传统 RAG 通常把文档上传到云端服务器进行向量化和检索，这会带来数据隐私、成本和延迟问题。本地检索可以把索引和检索全部放在浏览器或边缘设备上执行，文档内容不出本地。

## 核心步骤

1. 分块：把长文档切成适合检索的小片段，片段之间保留重叠，避免上下文被切断。
2. 分词：对中文和英文分别处理，中文使用单字加 bigram，英文使用小写词形。
3. 建索引：用 BM25 倒排索引对分块打分，也可以接入向量索引做混合检索。
4. 融合排序：使用 RRF 算法把关键词检索和向量检索的结果融合。
5. 组装上下文：按 token 预算把命中的片段拼成提示词，交给大模型回答。

## 隐私优势

整个流程可以在浏览器中完成，不需要把私有文档发送到第三方服务器，非常适合企业内部知识库和个人笔记场景。
