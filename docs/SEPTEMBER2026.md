## MoonRetrieve 的现有证据与差距

- 核心库用 MoonBit 实现，native、wasm-gc、js 由 CI 检查与测试；`examples/quickstart` 可运行。
- 本期可核查的提交包括倒排驱动检索、当前工具链适配、带引用清单的上下文、文档级评测和查询诊断轨迹。其实现与回归测试位于 `index.mbt`、`context.mbt`、`evaluation.mbt`、`trace.mbt` 及对应测试文件；不要用项目历史总代码量代替本期贡献。
- `Engine::trace` 让查询词、排名、来源与证据文本可导出；`evaluate` 可在固定标注集上比较文档级指标。`examples/evaluation-cases.json` 仅有三题，是 CI 冒烟，不是有统计意义的质量基准。
- 索引速度的 2,000 文档基准记录于 [性能记录](performance.md)。当前尚缺第三方语料、人工审定的足量查询集和与其他实现的同条件质量对照。
- 包已在 mooncakes.io 发布过 0.5.0；本期新接口仍在 GitHub `main`，尚未发新版。Gitlink 是否同步、报名和赛事群状态需要参赛者在平台核实。

下一阶段优先扩充并冻结标注集，给出质量回归阈值；再做一个可复现的端到端 RAG 演示，展示“导入文档、查询、引用核对、错误分析”。完成后发布新版本。单靠 API 数量、测试数量或奖项对标描述，不能代替真实用户场景的证据。
