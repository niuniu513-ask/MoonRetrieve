## 一、项目名称

MoonSearch — 纯 MoonBit 的本地全文检索与 RAG 检索库

## 二、项目定位（一句话）

用 MoonBit 实现一个可编译为 WASM、在浏览器/边缘设备上运行的本地全文检索与 RAG 检索库，让文档“不出本地”也能完成索引、检索和 LLM 上下文组装。

## 三、创新点

1. 本地优先的 RAG 架构：索引与检索全部在本地执行，数据不上云，隐私友好。
2. 中英文混合分词：中文单字 + bigram 保证单字查询可用，英文支持停用词与词干化。
3. BM25 与向量检索双路 + RRF 融合排序。
4. 按 token 预算组装带来源编号的 LLM 上下文。
5. 纯 MoonBit 实现，零 FFI，支持 wasm / wasm-gc / js / native 多后端。

## 四、项目类型

原创 MoonBit 开源库 + 开发工具（附带 CLI 与示例文档）。

## 五、技术路线

1. 分词器：ASCII 词形切分 + CJK 单字/bigram + 停用词 + 可选词干化。
2. 分块器：按段落分组、块间重叠、超长段落硬切。
3. BM25 倒排索引：增量添加、TF-IDF 加权、Top-K 排序。
4. 向量索引：余弦相似度暴力检索，预留 HNSW 升级空间。
5. 混合检索：RRF 融合关键词与向量结果。
6. 上下文组装：token 预算控制、来源编号。
7. 持久化：JSON 序列化/反序列化。
