## 项目简介

MoonRetrieve 是使用 MoonBit 从零实现的本地全文检索与 RAG（检索增强生成）检索库：文档在本地完成分词、分块、索引、检索与 LLM 上下文组装，数据不出本地，核心库无 FFI，可编译到 wasm / wasm-gc / js / native 多后端。已检索并对比 mooncakes 现有项目（Lucius646/MoonSearch、houjie/rag-mbt 等），本项目的定位是零 FFI 的混合检索 + RAG 上下文组装层，与搜索引擎内核、重 FFI 的 RAG 管线错开。仓库已包含核心库、CLI、示例文档、差异化说明和单元测试，GitHub Actions 覆盖 native 与 wasm-gc 构建。

## 核心功能范围

- 分词与分块：中英日分词（单字 + bigram、停用词、词干化），段落分块与重叠；
- 检索能力：BM25 Top-K、短语检索、布尔检索（AND/OR/-term）、前缀检索、JSON 持久化；
- 混合检索：余弦向量索引 + RRF 融合排序；
- 结果高亮与 LLM 上下文组装：查询词高亮、token 预算 + 来源编号；
- 索引管理：文档删除、统计信息；
- 一站式引擎 API 与 CLI（index / query / context / stats / phrase / boolean / prefix）。

## 本期实质新增工作

本项目不是对既有仓库的简单改名或文档更新。本期赛事周期内，项目围绕“让检索结果可评估、可解释、可组合”完成了可运行的功能扩展：新增 `evaluation.mbt` 及对应测试，提供 Precision、Recall、F1、MRR、MAP、R-Precision 和覆盖率等检索评估指标；新增 `query.mbt`、`explain.mbt`、`summary.mbt` 和 `suggest.mbt`，支持必选/排除/短语/前缀结构化查询、相关性解释、关键词与命中片段摘要、Unicode 查询纠错及前缀补全；新增 `result_ops.mbt`，支持结果归一化、过滤、分页、去重、融合、分组和多样化；同时补充 100 项回归测试、可运行的 `examples/quickstart`、CLI 冒烟测试和分词/建索引/检索基准测试，并通过 CI 覆盖 native、wasm-gc 与 js 目标。上述实现均已合并到公开仓库，主要新增提交包括 `661664e`（评估与查询工具）、`e83cad6`（快速示例）和 `24e8448`（CI 冒烟测试与基准测试），可由 GitHub 提交记录、源码、测试和工作流逐项核验。
