## 项目简介

MoonRetrieve 是使用 MoonBit 从零实现的本地全文检索与 RAG（检索增强生成）检索库：文档在本地完成分词、分块、索引、检索与 LLM 上下文组装，数据不出本地，核心库无 FFI，可编译到 wasm / wasm-gc / js / native 多后端。已检索并对比 mooncakes 现有项目（Lucius646/MoonSearch、houjie/rag-mbt 等），本项目的定位是零 FFI 的混合检索 + RAG 上下文组装层，与搜索引擎内核、重 FFI 的 RAG 管线错开。仓库已包含核心库、CLI、示例文档、差异化说明和单元测试，GitHub Actions 覆盖 native 与 wasm-gc 构建。

## 核心功能范围

- 分词与分块：中英日分词（单字 + bigram、停用词、词干化），段落分块与重叠；
- 检索能力：BM25 Top-K、短语检索、布尔检索（AND/OR/-term）、前缀检索、JSON 持久化；
- 混合检索：余弦向量索引 + RRF 融合排序；
- 结果高亮与 LLM 上下文组装：查询词高亮、内容预算、来源编号与结构化引用清单；
- 索引管理：文档删除、统计信息；
- 一站式引擎 API 与 CLI（index / query / context / stats / phrase / boolean / prefix）。

## 本期实质新增工作

本期完成了检索评估、结构化查询、相关性解释、摘要与命中片段、Unicode 查询纠错及结果分组、去重和融合。文档更新可直接替换旧分块；多来源上下文会限制同一原始文档的分块数量。相关代码与测试位于 `evaluation.mbt`、`query.mbt`、`explain.mbt`、`summary.mbt`、`suggest.mbt`、`result_ops.mbt`、`engine.mbt` 和 `context.mbt`。

普通与前缀检索已改为倒排驱动计分。在 2,000 文档的同一 wasm-gc 环境中，稀有词查询由约 62.8 µs 降至 0.45 µs，常见词由约 1.15 ms 降至 99 µs。负载构造和复现命令见 `docs/performance.md`。

RAG 上下文现可返回提示词、引用分块、来源编号、预算用量及跳过数量。CLI 提供 `--tokens`、`--diverse` 和 `--json`，示例可直接运行。项目有 113 项回归测试，GitHub Actions 覆盖 native、wasm-gc、js 三个目标；新增 API 目前位于 GitHub `main`，mooncakes 的 0.5.0 尚未包含这些更新。
