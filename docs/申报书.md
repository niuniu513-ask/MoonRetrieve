## 项目简介

MoonRetrieve 是使用 MoonBit 从零实现的本地全文检索与 RAG（检索增强生成）检索库：文档在本地完成分词、分块、索引、检索与 LLM 上下文组装，数据不出本地，核心库无 FFI，可编译到 wasm / wasm-gc / js / native 多后端。已检索并对比 mooncakes 现有项目（Lucius646/MoonSearch、houjie/rag-mbt 等），本项目的定位是零 FFI 的混合检索 + RAG 上下文组装层，与搜索引擎内核、重 FFI 的 RAG 管线错开。仓库已包含核心库、CLI、示例文档、差异化说明和单元测试，GitHub Actions 覆盖 native 与 wasm-gc 构建。

## 核心功能范围

- 分词与分块：中英日分词（单字 + bigram、停用词、词干化），段落分块与重叠；
- 检索能力：BM25 Top-K、短语检索、布尔检索（AND/OR/-term）、前缀检索、JSON 持久化；
- 混合检索：余弦向量索引 + RRF 融合排序；
- 结果高亮与 LLM 上下文组装：查询词高亮、token 预算 + 来源编号；
- 索引管理：文档删除、统计信息；
- 一站式引擎 API 与 CLI（index / query / context / stats / phrase / boolean / prefix）。
